AV1 edge green-line repro

One encoder, one picture, only the height changes. Used to check whether Chromium's D3D11VideoDecoder + NV12 leaks green rows on frame heights that are not a multiple of 8.

Why the "Eyeball" column exists: the canvas reads back the decoded frame. If the numbers are clean but the screen still shows a green line, the defect lives in the compositor or the video processor rather than in the decoder output. Note it as observed.

How to read the results

  1. Control group: if 1920x1088 and 720 are clean while 1920x886 is not, the trigger is the frame height, not the site or the content.
  2. Check the modulus: heights with h % 8 != 0 fail while h % 8 == 0 passes, so the granularity is the 8-row padding, not 16.
  3. Software decode: launch a separate profile with --disable-accelerated-video-decode. If every clip is clean, the defect is confined to the hardware path.
  4. Scaling: clean at 1:1 but green at 0.75x points at the video processor sampling outside the source rect. Zeroed NV12 (Y=0, U=V=0) renders as bright green, not black.
